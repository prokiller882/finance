# Индекс архитектурных решений

Навигационный слой к [`ARCHITECTURE-SPINE.md`](../../planning-artifacts/architecture/architecture-test-app-2026-11-22/ARCHITECTURE-SPINE.md) для эпиков и сторис. Источник истины — spine; этот файл пере-выводится `bmad-spec` при обновлении спеки и не заменяет Rule.

## Как цитировать

- В эпике и сторис пиши `AD-12` и одной фразой — какое требование Rule соблюдает история.
- AC ссылаются на FR из PRD; AD — на архитектурное ограничение. Не подменяй одно другим.
- Если реализация хочет отступить от AD — это конфликт: вынеси в Open Questions спеки или обнови spine. Локально «обойти» AD нельзя.

## Стабильность ID

- AD-1…AD-18 уникальны и непрерывны (проверено 2026-11-23, `lint_spine.py` — 0 findings; open questions закрыты 2026-11-23).
- Правка решения меняет его Rule на месте, ID сохраняется.
- Новое решение получает следующий свободный AD, начиная с AD-19.
- Переименование, переиспользование и перенумерация ID запрещены — на них ссылаются эпики, сторис и код-ревью.
